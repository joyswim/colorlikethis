# [✨feat]: 새로운 기능 추가 (작은 단위 포함)
# [🐛fix]: 버그 수정
# [📝docs]: 문서 수정
# [♻️refactor]: 코드 리팩토링 (기능을 제외한 성능 및 코드 로직 개선)
# [🎨format]: 코드 스타일링 (간단한 코드 변경, 클린코드)
# [💄design]: CSS 스타일링 (UI 변경점)
# [🔨chore]: 개발 환경 수정사항 (빌드, 패키지 매니저 등)
# [🔥remove]: 파일/폴더 삭제
# [🚚structure]: 파일/폴더 이동 및 이름 변경
# [💬comment]: 주석 추가/삭제/수정
# [📝test]: 테스트 추가/수정
